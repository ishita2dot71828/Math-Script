This is a simple project that let you write superscript and subscript of numericals, operators, latin alphabets and greek alphabets available in unicode using LaTeX. Users highlight the equation area and tab on the app and it converts it. 

The second release onwards, it require accessibility permission. 

Tested on: 
1. Redmi 12 5G(8/256)
2. Samsung S10 Fe(8/128)
